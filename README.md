Institut Perlindungan Rakyat RN dibangun demi kesejahteraan rakyat dari sisa-sisa kekacauan pasca kemerdekaan 1945. Ahmad Syaroji yang saat itu mendapatkan mandat langsung dari para laskar kemerdekaan menginginkan rakyat mendapatkan perlakuan yang setara seperti di pulau jawa. akhirnya atas desakan ahmad syaroji dan lobi para laskar kemerdekaan, pihak istana mengidahkan pembangunan institut perlindungan rakyat RN. Intitut Perlindungan Rakyat RN ketika di rancang akan memiliki mahasiswa, mata kuliah, jadwal, KRS, dan nilai.
